# Unified AOSP Device Tree for Redmi Note 15 5G (kunzite)

This repository contains the AOSP device configuration for the **Redmi Note 15 5G** (codenamed `kunzite`).

## Device Specifications

| Feature | Specification |
| :--- | :--- |
| **Device** | Redmi Note 15 5G |
| **Codename** | `kunzite` |
| **Architecture** | arm64-v8a |
| **Current Status** | In Development (WIP) |

## Repository Structure

* `AndroidProducts.mk` - Product build setup
* `BoardConfig.mk` - Board and architecture configuration
* `device.mk` - Device-specific configurations and packages
* `extract-files.sh` - Proprietary blobs extraction script
